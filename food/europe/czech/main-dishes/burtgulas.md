# 🇨🇿 Buřtguláš

Bramborový guláš se špekáčky, cibulí a paprikou, dochucený česnekem a majoránkou.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina                                      | Množství   | Upřesnění               |
| --------------------------------------------- | ---------- | ----------------------- |
| Máslo                                         | 60 g       | —                       |
| Špekáčky                                      | 600 g      | kvalitní                |
| Cibule                                        | 2 ks       | velké                   |
| Česnek                                        | 5 stroužků | —                       |
| Sladká paprika mletá nebo Uzená paprika mletá | 2 lžíce    | —                       |
| Kmín drcený                                   | 2 lžičky   | —                       |
| Gulášové koření                               | dle chuti  | maďarské                |
| Uzená paprika mletá                           | dle chuti  | —                       |
| Hladká mouka                                  | 3 lžíce    | —                       |
| Vývar nebo Voda                               | 2,5–3 l    | —                       |
| Brambory                                      | 800 g      | varný typ B             |
| Majoránka                                     | 1 lžíce    | sušená                  |
| Sůl                                           | dle chuti  | —                       |
| Pepř mletý                                    | dle chuti  | čerstvě namletý         |
| Ocet                                          | dle chuti  | volitelné, na dochucení |

### Příloha (volitelné)

| Surovina | Množství | Upřesnění                         |
| -------- | -------- | --------------------------------- |
| Chléb    | 0,5 ks   | kváskový, velikost kusu neuvedena |

## Postup

### 1. Opékání špekáčků

- V kastrolu se rozehřeje polovina másla.
- Špekáčky se nakrájí na čtvrtkolečka a opečou se ze všech stran dozlatova.
- Opečené špekáčky se dají stranou.

  > **Tip:** Špekáčky se opékají postupně, aby se dobře zatáhly.

### 2. Restování cibule a česneku

- Do kastrolu se přidá zbytek másla a cibule nakrájená na kostičky.
- Restuje se asi 10 minut, až bude cibule zlatavá.
- Přidá se nahrubo nasekaný česnek a restuje se další 3 minuty.

### 3. Koření a mouka

- Zasype se kmínem, mletou paprikou a moukou.
- Krátce se zarestuje, jen ať se koření rozvoní.

  > **Varování:** Koření nesmí připálit, paprika by zhořkla!

### 4. Základ guláše

- Zalije se vývarem nebo vodou a metličkou se rozmíchá dohladka.
- Pro hladší konzistenci lze směs promixovat ponorným mixérem.

### 5. Vaření s bramborami a špekáčky

- Do základu se dají orestované špekáčky a na kostky nakrájené brambory.
- Osolí se, opepří, přivede k varu a vaří se na mírném ohni 20 minut, až budou brambory měkké.

### 6. Dochucení a podávání

- Vmíchá se rozemnutá majoránka, případně se dochutí šplíchancem octa.
- Podává se s dobrým kváskovým chlebem.

  > **Tip:** Skvěle chutná s čerstvou pažitkou nebo cibulkou navrch.
