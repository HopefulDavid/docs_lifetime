# 🍞 Ďábelská topinka

Opečený chléb s pikantní směsí mletého hovězího masa, rajčat a kořenové zeleniny, posypaný sýrem.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina                   | Množství  | Upřesnění               |
| -------------------------- | --------- | ----------------------- |
| Chléb                      | 1 ks      | velikost kusu neuvedena |
| Ďábelské koření            | dle chuti | —                       |
| Sladká paprika mletá       | dle chuti | —                       |
| Pepř mletý                 | dle chuti | —                       |
| Sůl                        | dle chuti | —                       |
| Vinný ocet                 | 1 lžíce   | —                       |
| Mrkev                      | 3 ks      | menší                   |
| Petržel kořen              | 1 ks      | menší                   |
| Paprika                    | 1 ks      | —                       |
| Mleté hovězí maso          | 400 g     | —                       |
| Krájená rajčata v konzervě | 400 g     | —                       |
| Rajčatový protlak          | 2 lžíce   | —                       |
| Cibule                     | 1 ks      | —                       |
| Ghí                        | 2 lžíce   | na smažení              |
| Sýr                        | 150 g     | nastrouhaný             |

## Postup

### 1. Příprava zeleniny

- Nahrubo se nastrouhají 3 menší mrkve a 1 menší petržel.
- Cibule se nakrájí nadrobno.
- Paprika se nakrájí na kostičky.

### 2. Smažení

- Na přepuštěném másle se osmaží cibule.
- Přidá se mleté maso, osolí se, opepří a krátce se dohněda prosmaží.
- Přidá se protlak, konzerva rajčat, sladká paprika, ďábelské koření a ocet.
- Půl minuty se nechá probublávat.
- Přidá se mrkev, petržel a paprika.
- Přikryje se pokličkou a nechá se 1 hodinu probublávat.

### 3. Servírování

- Chléb se opeče.
- Na topinku se nanese hotová směs a posype se nastrouhaným sýrem.
