# 🍰 Míša řezy

Nepečený tvarohový dezert do misek s kakaovými sušenkami a čokoládovou polevou.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina           | Množství  | Upřesnění                                     |
| ------------------ | --------- | --------------------------------------------- |
| Tvaroh             | 1 vanička | velikost vaničky zdroj neuvádí                |
| Smetana ke šlehání | 1 hrnek   | vysokoprocentní, velikost hrnku zdroj neuvádí |
| Cukr               | dle chuti | —                                             |

### Poleva

| Surovina        | Množství  | Upřesnění                      |
| --------------- | --------- | ------------------------------ |
| Hořká čokoláda  | 1 tabulka | hmotnost tabulky zdroj neuvádí |
| Mléčná čokoláda | 1 tabulka | hmotnost tabulky zdroj neuvádí |
| Smetana         | 0,5 hrnku | velikost hrnku zdroj neuvádí   |
| Máslo           | 2 lžíce   | —                              |

### Sušenkový základ

| Surovina        | Množství | Upřesnění                 |
| --------------- | -------- | ------------------------- |
| Kakaové sušenky | 1 balení | hmotnost balení neuvedena |

> **Tip:** Cukr se přidává postupně a ochutnává se, aby náplň nebyla příliš sladká.

## Postup

### 1. Příprava smetany a tvarohu

- Smetana se vyšlehá do tuha.
- V jiné míse se vyšlehá tvaroh s cukrem a spojí se se smetanou.
- Nechá se vychladit v lednici.

### 2. Příprava polevy

- Do kastrůlku se dá voda a přivede se k varu.
- Na kastrůlek se položí miska, do které se rozláme čokoláda.
- Přidá se smetana a máslo a zahřívá se do rozpuštění.

  > **Varování:** Poleva se zahřívá pozvolna, aby se čokoláda nesrazila.

### 3. Dokončení

- Do misek se na dno dají rozdrobené kakaové sušenky.
- Přidá se tvarohová náplň a poleva.
- Nechá se vychladit v lednici.

  > **Tip:** Míša řezy jsou nejlepší dobře vychlazené, chutě se krásně propojí.
