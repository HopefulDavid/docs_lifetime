# 🍲 Gulášová polévka

Hovězí polévka s cibulovým základem, bramborami, paprikou a majoránkou.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina             | Množství   | Upřesnění                    |
| -------------------- | ---------- | ---------------------------- |
| Cibule               | 1 kg       | —                            |
| Brambory             | 700 g      | —                            |
| Hovězí maso          | 200 g      | —                            |
| Hovězí bujón         | 2–3 ks     | kostky                       |
| Sladká paprika mletá | 0,5 sáčku  | hmotnost sáčku zdroj neuvádí |
| Majoránka            | 0,5 sáčku  | hmotnost sáčku zdroj neuvádí |
| Česnek               | 3 stroužky | —                            |
| Sůl                  | dle chuti  | —                            |
| Pepř mletý           | dle chuti  | —                            |
| Voda                 | 1,5–2 l    | podle velikosti hrnce        |

> **Tip:** Najemno nakrájená cibule dá lepší chuťový základ.

## Postup

### 1. Příprava základu

- Cibule se nakrájí najemno a osmahne v hrnci dozlatova.
- Přidá se na kousky nakrájené hovězí maso a osmahne se s cibulí.

### 2. Přidání koření

- Zasype se červenou paprikou a krátce promíchá (nesmaží se dlouho, aby nezhořkla).

  > **Varování:** Paprika se opravdu jen zpění, jinak bude polévka hořká.

### 3. Vaření

- Zalije se 1,5–2 l vody.
- Přidá se sůl, pepř, masox, prolisovaný česnek, brambory na kostky a majoránka.
- Vaří se, dokud brambory nezměknou.

### 4. Servírování

- Podává se horká, ideálně s čerstvým chlebem.

  > **Tip:** Skvěle chutná s čerstvou petrželkou navrch.
