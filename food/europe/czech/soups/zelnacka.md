# 🥬 Zelňačka

Sytá polévka z kysaného zelí, klobásy a brambor zjemněná smetanou.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina             | Množství   | Upřesnění                 |
| -------------------- | ---------- | ------------------------- |
| Máslo                | 2 lžíce    | —                         |
| Cibule               | 1 ks       | —                         |
| Klobása              | 2 ks       | —                         |
| Brambory             | 400 g      | —                         |
| Voda nebo Vývar      | 1,5–2 l    | —                         |
| Bobkový list         | dle chuti  | —                         |
| Nové koření          | dle chuti  | —                         |
| Pepř celý            | dle chuti  | —                         |
| Kmín                 | dle chuti  | —                         |
| Sladká paprika mletá | dle chuti  | —                         |
| Sůl                  | dle chuti  | —                         |
| Cukr                 | dle chuti  | —                         |
| Kysané zelí          | 400–500 g  | i trochu láku podle chuti |
| Smetana ke šlehání   | 200–250 ml | —                         |
| Majoránka            | dle chuti  | —                         |

## Postup

### 1. Restování základu

- Na másle se osmaží cibule dozlatova.
- Přidá se klobása nakrájená na kostičky a orestuje se.

### 2. Vaření brambor a koření

- Přidají se brambory nakrájené na kostičky a zalijí se vodou nebo vývarem.
- Ochutí se bobkovým listem, novým kořením, pepřem, kmínem, paprikou, solí a cukrem.
- Vaří se asi 12–15 minut, dokud brambory téměř nezměknou.

  > **Tip:** Cukr vyvažuje kyselost zelí, přidává se dle chuti.

### 3. Přidání zelí a další vaření

- Přidá se pokrájené kysané zelí (podle chuti i trochu láku).
- Vaří se dalších 10 minut.

  > **Varování:** Zelí se přidává až po změknutí brambor, aby nebyly tvrdé.

### 4. Dokončení a dochucení

- Vyjme se bobkový list a kuličky koření.
- Vmíchá se smetana ke šlehání (předem ohřátá se nesrazí) a krátce se povaří.

  > **Tip:** Smetana se přidává pomalu za stálého míchání.

- Dochutí se solí a čerstvě mletým pepřem a přidá se majoránka.
