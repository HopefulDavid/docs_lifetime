# 🥬 Noky se špenátem

Noky se špenátem, česnekem a smetanovou omáčkou, posypané parmezánem.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina           | Množství   | Upřesnění                 |
| ------------------ | ---------- | ------------------------- |
| Mražený špenát     | 1 balení   | hmotnost balení neuvedena |
| Noky               | 500 g      | —                         |
| Parmezán           | 1 balení   | hmotnost balení neuvedena |
| Smetana ke šlehání | 200 ml     | —                         |
| Česnek             | 2 stroužky | —                         |
| Rostlinný olej     | 1 lžíce    | —                         |
| Pepř mletý         | dle chuti  | —                         |
| Sůl                | dle chuti  | —                         |

## Postup

### 1. Příprava sýra a noků

- Nastrouhá se parmezán.
- Noky se uvaří podle návodu na obalu.

### 2. Příprava omáčky

- Na oleji se krátce osmaží prolisovaný česnek.
- Přidá se špenát a nechá se změknout.
- Zalije se smetanou ke šlehání.
- Promíchá se a přidá se většina nastrouhaného parmezánu.
- Osolí se, opepří a krátce povaří, dokud omáčka nezhoustne.

### 3. Dokončení a podávání

- Do hotové omáčky se zamíchají uvařené noky.
- Posype se zbytkem parmezánu.
