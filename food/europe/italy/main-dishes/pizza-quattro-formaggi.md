# 🍕 Pizza Quattro Formaggi

Domácí pizza s tenkým smetanovým základem, mozzarellou, gorgonzolou a parmezánem.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina                       | Množství  | Upřesnění                          |
| ------------------------------ | --------- | ---------------------------------- |
| Pizza těsto nebo Listové těsto | 1 ks      | hmotnost kusu neuvedena            |
| Smetana ke šlehání             | 3–5 lžic  | —                                  |
| Mozzarella                     | 1 balení  | kuličky, hmotnost balení neuvedena |
| Gorgonzola                     | 1 balení  | hmotnost balení neuvedena          |
| Parmezán                       | 1 balení  | hmotnost balení neuvedena          |
| Sůl                            | dle chuti | —                                  |
| Pepř mletý                     | dle chuti | —                                  |

## Postup

### 1. Předehřátí trouby

- Trouba se předehřeje na 220 °C.
- Při horkovzduchu stačí 200–210 °C.
- Plech patří spíš do spodní nebo střední části trouby, aby se dobře propeklo i dno.

### 2. Smetanový základ

- Do misky se dají 3–5 lžic smetany ke šlehání.
- Přidá se špetka soli a trochu pepře.
- Pro hustší základ lze do smetany nastrouhat trochu parmezánu.

  > **Varování:** Smetana se nanáší jen v tenké vrstvě.

### 3. Příprava těsta

- Těsto na plechu se lehce propíchá vidličkou, hlavně uprostřed.
- Listové těsto se nejdřív 5–7 minut samotné předpeče, aby se zpevnilo.
- Pizza těsto se nepředpéká a rovnou se pokračuje smetanou a sýry.

### 4. Skládání pizzy

- Těsto se potře tenkou vrstvou smetanového základu a kraje zůstanou volné.
- Mozzarella se předem osuší ubrouskem, aby nepustila příliš vody.
- Navrch se dají nejdřív napůl rozkrojené kuličky mozzarelly, potom kousky gorgonzoly a nastrouhaný parmazán.

### 5. Pečení

- Peče se přibližně 10–15 minut podle typu těsta.
- Hotovo je ve chvíli, kdy jsou kraje zlaté, sýr bublá a spodek není bledý.

### 6. Dokončení

- Po vytažení se pizza nechá 2–3 minuty stát a až potom se krájí.
