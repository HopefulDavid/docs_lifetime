# 🥒 Gazpacho

Studená rajčatová polévka s paprikou, okurkou a vinným octem, připravená bez vaření.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina                         | Množství   | Upřesnění |
| -------------------------------- | ---------- | --------- |
| Rajčata podlouhlá                | 3 ks       | —         |
| Rajčata                          | 3 ks       | —         |
| Rajče masité                     | 1 ks       | červené   |
| Červená paprika                  | 1 ks       | masitá    |
| Zelená paprika nebo Bílá paprika | 2 ks       | nemasitá  |
| Okurka                           | 1 ks       | —         |
| Cibule                           | 1 ks       | střední   |
| Česnek                           | 1 stroužek | —         |
| Vinný ocet                       | 2 lžíce    | —         |
| Sůl                              | 1 lžička   | malá      |

## Postup

### 1. Příprava zeleniny

- Všechna zelenina se důkladně omyje.
- Nakrájí se na menší kousky.

  > **Tip:** Oloupaná okurka dá jemnější chuť.

### 2. Mixování a dochucení

- Nakrájená zelenina se vloží do mixéru.
- Přidá se vinný ocet a sůl.
- Rozmixuje se dohladka.

  > **Tip:** Příliš hustou směs zředí trocha studené vody.

### 3. Servírování

- Podává se vychlazené, ideálně s kostkami ledu.
- Ozdobí se nasekanou zeleninou nebo krutony.

  > **Varování:** Gazpacho se nesmí vařit, ztratilo by svěžest.
