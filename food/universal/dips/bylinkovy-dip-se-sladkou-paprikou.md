# 🌿 Bylinkový dip se sladkou paprikou

Svěží dip ze zakysané smetany, česneku a bylinek k zelenině, pečivu nebo grilovanému masu.

## Ingredience

Množství platí pro jednu původní dávku.

Počet porcí není uveden.

| Surovina             | Množství    | Upřesnění                                  |
| -------------------- | ----------- | ------------------------------------------ |
| Zakysaná smetana     | 0,5 kelímku | velký kelímek, jeho hmotnost zdroj neuvádí |
| Sladká paprika mletá | dle chuti   | —                                          |
| Pizza koření         | dle chuti   | —                                          |
| Bazalka              | dle chuti   | čerstvá nasekaná nebo sušená               |
| Česnek               | 1 stroužek  | větší                                      |
| Sůl                  | dle chuti   | —                                          |
| Pepř mletý           | dle chuti   | —                                          |

> **Tip:** Čerstvá bazalka dá výraznější chuť.

## Postup

### 1. Příprava dipu

- Zakysaná smetana se dá do misky.
- Přidá se sladká paprika, pizza koření, nasekaná bazalka, prolisovaný česnek, sůl a pepř.
- Vše se důkladně promíchá.

  > **Varování:** Česnek se přidává postupně, aby dip nebyl příliš ostrý.

### 2. Servírování

- Podává se vychlazený, ideálně s čerstvou zeleninou, pečivem nebo chipsy.

  > **Tip:** Dip je skvělý i jako omáčka k masu z grilu.
